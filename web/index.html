BepInEx on your Deck

Launch Graveyard Keeper 2 through Proton once, then close it and any other Wine or Proton games. Install BepInEx prepares its loading setting; Deck Sync copies the BepInEx files and mods from your PC.

The original registry is backed up. Your Steam launch options stay unchanged.

Existing launch options or manual setup

The matching WINEDLLOVERRIDES="winhttp=n,b" launch option becomes redundant after setup. A conflicting WINEDLLOVERRIDES value can still override this setting; remove only the conflicting winhttp entry and preserve other options.

As a manual alternative, use this Steam launch option:

WINEDLLOVERRIDES="winhttp=n,b" %command%

This uses Windows BepInEx with the Windows game through Proton. Linux BepInEx is not a replacement for it.

Ready to compare

GK2MT verifies that the PC and Deck have the same installed Steam game build before comparing mods. Different or unknown builds stop the comparison. Replaced mod files are backed up; save files are never copied.

Matching mod files reduces mismatch risk; it does not prove save compatibility. Workshop files are copied without changing Steam subscriptions.
